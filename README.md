TrussIQ 🏗️Interactive 2D Structural Physics & Finite Element Analysis (FEA) SimulatorTrussIQ is a web-based, real-time 2D Finite Element Analysis application designed for STEM students, robotics teams (VEX/FTC), and engineering enthusiasts. It allows users to visually build truss bridge structures, apply external nodal forces, define supports, and analyze member stresses and deflections in real-time.✨ Features📐 Interactive Canvas & Grid System: Smooth HTML5 2D canvas with grid snapping (10px / 20px / 50px increments).⚙️ Direct Stiffness Method (DSM) Engine: Pure TypeScript implementation of 2D pin-jointed truss matrix analysis ($[K]\{u\} = \{F\}$).🎨 Stress Heatmap Visualization: Visual color-coded beam stress ratios ($\sigma / \sigma_{\text{yield}}$) ranging from low-stress green to failure red.📈 Animated Deflection Mode: Overlay showing exaggerated real-time structural deformation under load.🏗️ Preset Library: One-click preset template loading for Howe, Pratt, Warren, and Cantilever trusses.📊 Live Member Inspector: Detailed table showing axial forces ($N$), stresses ($\text{MPa}$), safety factors, and tension/compression states.📐 Mathematical FoundationTrussIQ solves 2D pin-jointed truss systems using the Direct Stiffness Method.1. Element Stiffness Matrix ($k^e$)For a truss element connected between two nodes with Young's Modulus $E$, cross-sectional area $A$, and length $L$ at angle $\theta$:$$k^e = \frac{EA}{L} \begin{bmatrix} c^2 & cs & -c^2 & -cs \\  cs & s^2 & -cs & -s^2 \\  -c^2 & -cs & c^2 & cs \\  -cs & -s^2 & cs & s^2 \end{bmatrix} \quad \text{where } c = \cos\theta, \; s = \sin\theta$$2. Global Matrix Assembly & SolvingAssemble $k^e$ into the Global Stiffness Matrix $[K_{\text{global}}]$.Apply boundary condition constraints by reducing constrained degrees of freedom.Solve for nodal displacements:$$\{u\} = [K_{\text{reduced}}]^{-1} \{F_{\text{applied}}\}$$3. Member Axial Force & StressCalculate the axial force $N$ and normal stress $\sigma$:$$N = \frac{EA}{L} \left( (u_{x2} - u_{x1})\cos\theta + (u_{y2} - u_{y1})\sin\theta \right)$$$$\sigma = \frac{N}{A}$$🛠️ Tech StackFrontend: React 18 / Next.js 14Styling: Tailwind CSS + Lucide React IconsGraphics: HTML5 Canvas API (High-DPI / Retina scaled)Language: TypeScript🚀 Getting StartedPrerequisitesNode.js 18.0 or highernpm / pnpm / yarnInstallationClone the repository:git clone https://github.com/your-username/truss-iq.git
